# 画像差し替えガイド

`intro.html`（自己紹介ページ）で使う画像を、このフォルダに置くだけで自動的に表示されます。
ファイル名は **以下のとおり固定** にしてください（大文字小文字も区別されます）。

## 必要なファイル一覧

| ファイル名 | 表示場所 | 推奨サイズ・形式 |
|---|---|---|
| `profile.jpg` | ヒーロー左の丸いアバター（「笹」の代わりに表示） | 正方形 / 500×500px 以上 / JPG または PNG |
| `logo.png` | ヒーロー右上の屋号ロゴ | 横長 / 高さ150px程度 / 背景透過PNG推奨 |
| `gallery-1.jpg` | ギャラリー1枚目（セミナー登壇） | 横長 4:3 / 1200×900px 程度 / JPG |
| `gallery-2.jpg` | ギャラリー2枚目（お客様サポート） | 同上 |
| `gallery-3.jpg` | ギャラリー3枚目（LINE構築事例） | 同上 |
| `gallery-4.jpg` | ギャラリー4枚目（スマホレッスン） | 同上 |
| `gallery-5.jpg` | ギャラリー5枚目（商工会・団体活動） | 同上 |
| `gallery-6.jpg` | ギャラリー6枚目（BNI チャプター） | 同上 |

## 差し替え方法（GitHub Web上）

1. このフォルダ（`images/`）をブラウザで開く
2. 「Add file」→「Upload files」をクリック
3. 上記の名前にリネームした画像をドラッグ&ドロップ
4. 「Commit changes」で保存
5. 数分後、`intro.html` を開くと自動で反映されます

## 任意項目について

- **ファイルが無い場合**：枠（プレースホルダー）が表示されたままになります（崩れません）
- **キャプション（写真の下の説明文）を変更したい**：`intro.html` 内の `<div class="caption">…</div>` を編集してください
- **ギャラリーの並び順を変更したい**：`gallery-1` 〜 `gallery-6` の番号で並びが決まります

## ファイル形式について

- 顔写真・実績写真：**JPG（.jpg）** がおすすめ（容量が小さい）
- ロゴ・イラスト：**PNG（.png）** がおすすめ（背景透過できる）
- 1枚あたり **2MB以下** を目安に圧縮するとページが軽くなります
